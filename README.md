## 下载后立即试玩

本项目没有安装依赖或构建步骤。克隆或下载解压后，在 Windows 双击根目录的 `试玩.cmd`；它会用默认浏览器打开游戏。也可直接用浏览器打开 `dist/index.html`。

进度保存在浏览器本地。换电脑后重新从新档开始；同一台电脑用同一个浏览器再次打开时，已收集结局会保留。

## 归档与版本

本目录就是本会话的唯一项目根目录及持久归档入口。目录名使用首次会话日期260911；后续日期继续更新本目录。

本机日期归档仅保存摘要和项目快捷方式，不随 GitHub 同步；实际项目内容以本仓库为准。

Markdown使用固定文件名，页首维护日期与AMD版本，Git保存历史；图形发布文件名携带日期与版本。每次正式更新生成文件时日期改为当次会话日期、AMD编号递增，并更新相关链接。

项目采用本地 Git 与 GitHub 私有仓库同步；状态文件为 `.codex/git-policy.json`。Demo为无依赖静态H5，可直接打开或用任意本地HTTP服务实时预览；未部署公开站点，未安装新的编辑器或扩展。
