## 下载后立即试玩

本项目没有安装依赖或构建步骤。公开仓库：[Skrikkk/jianglai-vn-demo](https://github.com/Skrikkk/jianglai-vn-demo)。电脑可下载 ZIP 并解压：Windows 双击根目录的 `试玩.cmd`，Mac 在浏览器打开 `dist/index.html`。手机请打开 [在线试玩页](https://skrikkk.github.io/jianglai-vn-demo/)；直接在 iPhone 下载仓库 ZIP 后打开本地 HTML 的表现取决于系统文件预览，不作为推荐入口。

iPhone/iPad 请在 Safari 中横向握持设备。浏览器可能不允许网页自动锁定横屏，当前Demo会提示转动设备；不要求进入全屏。Safari 真机排版、触摸擦除和存档持久性仍需设备实测。公开仓库中的文案与图片没有附带再分发许可。

进度保存在浏览器本地。换电脑后重新从新档开始；同一台电脑用同一个浏览器再次打开时，已收集结局会保留。

打开后先显示一周目封面，进入主界面可选新游戏、继续游戏、设置或退出到封面；普通结局E1—E4全部收齐后，封面自动换为二周目版本。游玩书页左侧插画右下角只有放大镜图标，点击可查看完整插画，关闭后返回当前剧情。主界面还保留结局回看与调试入口。
